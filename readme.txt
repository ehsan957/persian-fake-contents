Generate Persian/Farsi dummy posts, pages and custom post types with block content, images, tags and comments. Includes WP-CLI commands.

== Description ==
**محتوای جعلی فارسی**
ابزاری برای طراحان و توسعه‌دهندگان وردپرس فارسی تا در چند ثانیه پست، برگه یا پست‌تایپ سفارشی با متن فارسی بسازند؛ مناسب برای تست قالب‌ها، چیدمان‌ها، آرشیوها و سایدبارها.

A tool for Persian WordPress developers to quickly create realistic Persian/Farsi dummy content for testing themes and plugins.

= Features =
* ساخت محتوا برای **پست‌ها، برگه‌ها و پست‌تایپ‌های سفارشی**
* محتوای **بلوکی** (تیتر، پاراگراف، فهرست و نقل‌قول) یا HTML کلاسیک
* جمله‌بندی طبیعی‌تر با علائم نگارشی فارسی (، . ؟) و واژه‌های پرکاربرد
* وضعیت انتشار: منتشرشده، پیش‌نویس، در انتظار بازبینی، خصوصی
* نویسنده و دسته‌بندی مشخص یا **تصادفی**
* برچسب‌ها و **دیدگاه‌های** فارسی تصادفی
* پخش تاریخ انتشار در N روز گذشته
* تصویر شاخص: **تصویر ساده‌ی محلی (GD)** یا عکس تصادفی از picsum.photos
* فرمان‌های **WP-CLI** برای ساخت تعداد زیاد محتوا
* نمایش و **حذف یک‌جای** همه‌ی محتوا، تصاویر، دیدگاه‌ها و برچسب‌های ساخته‌شده (شامل محتوای نسخه‌های قبلی)
* بدون نیاز به افزونه‌ی SQLite در PHP

= WP-CLI =
`wp persian-fake generate --count=50 --category=random --tags=3 --comments=5 --image=placeholder --days=90`
`wp persian-fake list`
`wp persian-fake purge --yes`

برای دیدن همه‌ی گزینه‌ها: `wp help persian-fake generate`

= External services =
اگر گزینه‌ی «Random photo (downloaded from picsum.photos)» را برای تصویر شاخص انتخاب کنید، افزونه برای هر پست یک تصویر تصادفی از سرویس [Lorem Picsum](https://picsum.photos/) دانلود می‌کند. در این درخواست هیچ اطلاعاتی از سایت یا کاربران شما ارسال نمی‌شود (فقط آدرس IP سرور شما برای سرویس قابل مشاهده است). با گزینه‌های دیگر هیچ درخواست خارجی‌ای انجام نمی‌شود.

If you choose "Random photo (downloaded from picsum.photos)" as the featured image source, the plugin downloads one random image per post from [Lorem Picsum](https://picsum.photos/). No site or user data is sent; the service only sees your server's IP address. Other options make no external requests.

== Frequently asked questions ==

= راهنمای استفاده =
1. افزونه را نصب و فعال کنید.
2. به **ابزارها ← Persian Fake Contents** بروید.
3. تعداد و گزینه‌ها را انتخاب کرده و دکمه‌ی Generate را بزنید (تا ۵۰ مورد در هر بار؛ برای تعداد بیشتر از WP-CLI استفاده کنید).
4. برای پاک کردن همه‌چیز، دکمه‌ی «Delete all fake content» را در همان صفحه بزنید.

= منوی افزونه کجا رفت؟ =
از نسخه‌ی ۲.۰ صفحه‌ی افزونه به زیرمنوی **ابزارها** منتقل شده است.

= آیا محتوای ساخته‌شده با نسخه‌های قبلی هم حذف می‌شود؟ =
بله. همه‌ی محتوایی که با نسخه‌های ۱.x ساخته شده هم در فهرست نمایش داده و حذف می‌شود.
